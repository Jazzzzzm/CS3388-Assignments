# CS3388 Assignments
This repository contains all assignments from CS3388 - Graphic course from Western University.

## Assignment 1
This assignment consists of an introduction to OpenGL and GLFW coding.

## Assignment 2
This assignment introduces simple animation and using math to draw dot art.

## Assignment 3
This assignment combines user interaction, splines, and rendering to make a spline drawing tool.

## Assignment 4
This assignment recretes Link's house from Ocarina of Time with a controllable camera and rendering models with texture.

## Assignment 5
This assignment uses marching cubes, math functions, and Phong shaders to generate a 3D surface.
